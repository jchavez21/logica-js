# logica-js

Ejercicios de lógica de programación en JavaScript: recorrer arreglos con `for` y `for...of`, contar, sumar, sacar promedios y encontrar el mayor y el menor, además de cálculos con datos que escribe el usuario. Los hice para practicar los fundamentos de programación durante mi formación.

## Ejercicios
| Archivo | Qué hace |
|---|---|
| `aprobados.js` | Cuenta cuántas notas aprueban (≥ 3.0) y cuántas reprueban |
| `promedio.js` | Suma las notas y calcula el promedio |
| `extremos.js` | Encuentra la nota más alta y la más baja |
| `compras.js` | Muestra una lista de compras numerada |
| `dias.js` | Recorre los días de la semana y muestra el último |
| `precio-menor.js` | Encuentra el precio más bajo de una lista |
| `temperaturas.js` | Cuenta los días con más de 25 grados y busca la temperatura mínima |
| `diacaluroso.js` | Encuentra la temperatura más alta y en qué día fue |
| `minutos.js` | Convierte minutos a horas y minutos (pide el dato al usuario) |
| `caja.js` | Calcula el cambio de una compra y en qué billetes y monedas entregarlo |
| `prueba.js` | Pide tu nombre y te saluda |

## Herramientas
- JavaScript
- Node.js
- [prompt-sync](https://www.npmjs.com/package/prompt-sync) (para leer datos desde la terminal)

## Cómo ejecutar un ejercicio
```
npm install
node nombre-del-archivo.js
```
